# Food Delivery Website 🍔🍕🥗

A modern *food delivery web application* built using *React, **Redux, and **React Router*. Browse restaurants, explore menus, add items to your cart, and enjoy a seamless online ordering experience.

---

## Features

- Browse a list of restaurants and their menus
- Add food items to the cart
- Redux state management for cart and user data
- React Router for smooth navigation
- Responsive design for mobile and desktop
- Real-time cart updates and total price calculation
- Easy integration with APIs for real orders (optional)

---

## Tech Stack

- *Frontend:* React, Redux, React Router
- *Styling:* CSS / SCSS / Tailwind CSS (customize as per your project)
- *State Management:* Redux
- *Routing:* React Router DOM
- *Optional:* Axios or Fetch API for backend data fetching
